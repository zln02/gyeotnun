# corpus - 곁눈 근거 데이터

담당: 장지석 (코퍼스·RAG), 김유리 (검색 대조)

## 무엇이 들어가는가

| 폴더 | 내용 | 쓰는 곳 |
|---|---|---|
| `public_data/` | 공공데이터 **577건** 원문 JSON | `services/search.py` 대조 근거 |
| `training_cards/` | 매일 5분 훈련 카드 | `services/rag.py` → `GET /training/today` |

## public_data 배치 안내

1. 원문을 아래 스키마의 **JSON 배열** 파일로 만들어 `corpus/public_data/` 에 넣는다.
   - 파일명 규칙: `{도메인}_{일련번호}.json` (예: `policy_001.json`, `health_002.json`)
   - 한 파일에 여러 건을 배열로 담아도 되고, 도메인별로 나눠도 된다.
2. 용량 때문에 **원문 파일은 git에 커밋하지 않는다** (`.gitignore` 에서 제외 처리됨).
   팀 공유 드라이브에 올리고, 각자 로컬로 내려받아 이 폴더에 둔다.
3. `.gitkeep` 은 폴더 유지용이므로 지우지 말 것.

### 문서 1건 스키마

```json
{
  "doc_key": "policy_basic_pension_2026",
  "title": "기초연금 지급 대상 및 금액 안내",
  "body": "65세 이상 중 소득인정액이 선정기준액 이하인 분에게 지급합니다. ...",
  "publisher": "보건복지부",
  "url": "https://basicpension.mohw.go.kr/",
  "domain": "policy",
  "published_at": "2026-01-02"
}
```

**필수 규칙**
- `url` 이 없는 문서는 근거로 쓰지 않는다. (`search.py` 가 자동으로 걸러낸다)
  곁눈은 사용자에게 "직접 눌러서 확인해 보세요"라고 말하는 서비스이므로,
  누를 수 있는 실제 링크가 없는 근거는 의미가 없다.
- `publisher` 는 발행 기관 정식 명칭을 쓴다. 약어 금지.
- `body` 는 **원문 그대로** 넣는다. 요약하거나 각색하지 않는다.
  훈련 카드의 정답 근거가 되므로 원문 보존이 중요하다.

### 도메인 분류 (4종)

`policy` 정부 지원금·연금·복지 / `health` 건강·의약 / `finance` 투자·금융 / `news` 일반 시사

## training_cards

- `sample_cards.json` 에 유형별 샘플 3건이 들어 있다. 형식을 그대로 따라 늘려 나간다.
- 카드 지문은 반드시 `public_data` 원문에서 파생시킨다.
  '있을 법한 가짜뉴스'를 창작해 넣지 않는다 — 훈련 자체가 허구가 된다.
- 변형은 결정적 규칙으로만: 조건절 삭제 / 숫자 변경 / 기관명 삭제 / 제목만 남기기.
