## 3. 로컬 전환 시 절감액

### 3-1. OCR + 임베딩만 로컬 (질문 생성은 외부 API 유지)

| | 도입가 | 정상가 |
|---|---|---|
| 현재 (이미지 포함) | 28.28원 | 42.42원 |
| 로컬 전환 후 | 23.81원 | 35.72원 |
| **절감** | **4.47원 (15.8%)** | **6.70원 (15.8%)** |

**비용만 놓고 보면 로컬 전환의 명분은 약하다.** 건당 4~7원을 아끼자고
easyocr(상주 836MB) + bge-m3(상주 1.1GB)를 서버에 올리는 셈이다.
**로컬 전환의 진짜 이유는 비용이 아니라 개인정보**다(이미지·텍스트를 외부로
보내지 않는 것). 그 근거는 `ocr_comparison.md`, `local_embeddings_report.md` 참고.

### 3-2. 전부 로컬 (질문 생성까지 대체)

**API 비용은 0원이 된다.** 다만 이건 계산이 아니라 산술이고, 실제로 가능한지는
**측정한 적이 없다.** 아래 셋을 확인하기 전에는 "0원"이라고 말할 수 없다.

| 미확인 항목 | 상태 |
|---|---|
| 로컬 LLM 의 질문 생성 품질 | **측정 안 함.** 곁눈의 핵심은 "판정하지 않는 질문"이고, `validate_question()` 가드레일(금지어·2문장·출처 검증)을 통과해야 한다. 통과율 미측정 |
| CPU 추론 속도 | **사실상 불가능에 가깝다** (아래 근거) |
| 서버 비용 증가 | GPU 인스턴스 필요 → **현재 $80/월보다 오른다. 구체적 금액 미확인** |

**속도 근거(자릿수 추정, 실측 아님)**: 같은 서버에서 bge-m3(0.57B 파라미터)로
임베딩 **1건에 558ms** 가 걸렸다. 이건 순전파 1회다. 반면 질문 생성은 7B 급
모델로 **약 300 토큰을 순차 생성**해야 한다 — 모델 크기 12배 × 순차 300회다.
현재 Sonnet 으로 6초 걸리는 작업이 CPU 로컬에서는 **분 단위**가 될 가능성이 높다.
시니어 대상 서비스에서 감당할 수 없는 수준이다.

**결론**: 전부 로컬은 **API 비용 0원 대신 GPU 서버 비용과 품질 리스크를 떠안는
교환**이다. 지금 데이터로는 권하기 어렵고, 하려면 (1) 로컬 LLM 가드레일 통과율,
(2) GPU 서버 실제 월 요금, (3) 응답 시간을 먼저 측정해야 한다.

## 5. 사용 빈도 가정

**★ 근거의 한계를 먼저 밝힌다.** 자녀 설문의 "매일 또는 가끔 훈련 의향 73.1%"는
**이 저장소에 원자료가 없어 검증하지 못했다.** 그리고 그 문항은 **"훈련 의향"**
이지 **"확인 요청 빈도"** 가 아니다 — 훈련(5분 학습)과 확인 요청(의심 문자 검사)은
다른 행동이고, 비용이 발생하는 쪽은 후자다. 따라서 73.1% 를 건수 산출의 직접
근거로 쓸 수 없다.

아래는 **전부 가정**이며, 8/5 사용성 테스트에서 실제 행동을 관측해 교체해야 한다
(이벤트 계측이 이미 붙어 있으므로 참가자당 확인 요청 수를 셀 수 있다).

| 시나리오 | 1인 월 확인 요청 | 근거·가정 |
|---|---|---|
| **저** | 2건 | 의심 문자를 받았을 때만 사용. 보수적 하한 |
| **중** | 8건 | 주 2회. "가끔"이라는 응답을 주 단위 사용으로 해석한 가정 |
| **고** | 30건 | 매일 1건. 설문의 "매일"에 대응하는 상한 |

이 지점부터는 질문 생성 비용 최적화(캐시 적중률 개선, 턴 수 축소, 더 싼 모델)가
로컬 OCR 전환보다 훨씬 큰 레버다.

## 6. 정리

1. **건당 28.28원(도입가) / 42.42원(정상가)**, 텍스트만이면 23.82원 / 35.73원.
2. **비용의 79.8% 가 확인 질문 생성**이다. OCR·임베딩은 합쳐서 15.8%.
3. 따라서 **로컬 OCR·임베딩 전환의 절감은 15.8%(건당 4~7원)** 에 그친다 —
   전환의 명분은 비용이 아니라 개인정보다.
4. **전부 로컬은 API 0원이지만** 로컬 LLM 품질·CPU 속도·GPU 서버비가 전부
   미측정이다. 지금 근거로는 권하기 어렵다.
5. 서버는 Lightsail $80/월(공식 요금). **실제 청구액은 미확인.**
6. 사용 빈도는 **전부 가정**이다. 8/5 테스트의 이벤트 계측으로 교체할 것.
