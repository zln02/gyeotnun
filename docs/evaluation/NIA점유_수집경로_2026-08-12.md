# 1부 — NIA 297건 후보군 점유

## 결론: 후보군에도 안 들어온다. 제외해도 지표가 한 자리도 안 움직인다

"기여 0%가 후보에 안 들어온다는 뜻은 아니다"는 지적이 맞아서 따로 쟀는데,
**후보군에서도 0이었다.**

### (1) Top-20 후보군 점유율 — 확대 112건

| | 값 |
|---|---:|
| 후보 총계 | 273개 |
| 그중 NIA | **0개 (0.0%)** |
| 케이스당 평균 NIA | **0.00개 / 20** |
| NIA 가 1개 이상 낀 케이스 | **0/112건** |

### (2) Top-5 실패 케이스에서 더 높은가 — 아니다

| 구분 | 건수 | 케이스당 NIA 평균 |
|---|---:|---:|
| Top-5 성공 | 54 | 0.00 |
| Top-5 실패 | 27 | 0.00 |

실패 쪽에도 NIA 가 없다. **정답이 NIA 에 밀려난 게 아니다.**

### (3) NIA 를 검색 대상에서만 제외하고 재측정 — 네 지표 전부 동일

| 지표 | 확대 112건 현재 → 제외 | 홀드아웃 30건 현재 → 제외 |
|---|---|---|
| 축1 판정 | 81/112 (72.3%) → **동일** | 23/30 (76.7%) → **동일** |
| 정상 오판 | 1/37 (2.7%) → **동일** | 1/10 (10.0%) → **동일** |
| 축2 위험행동 있음 | 15/39 (38.5%) → **동일** | 2/11 (18.2%) → **동일** |
| 축2 위험행동 없음 | 2/70 (2.9%) → **동일** | 3/18 (16.7%) → **동일** |

**한 자리도 안 움직였다.** NIA 297건은 검색에 이롭지도 해롭지도 않다.
지금 상태에서 빼는 것은 지표상 아무 이득이 없다 —
**그러므로 뺄 이유도 없다**(기획서 2.3 정정 이력을 만들 근거가 안 된다).

> 다만 코퍼스의 28% 가 검색에 한 번도 쓰이지 않는다는 사실 자체는 남는다.
> 이건 성능 문제가 아니라 **코퍼스 구성 설명의 문제**다. 심사에서
> "1,052건 중 297건은 통계 보고서라 문자 대조에 쓰이지 않는다"고
> 물으면 답할 준비가 필요하다.

## ★ 그런데 이 측정에서 더 중요한 게 나왔다 — Top-3 = Top-5 의 진짜 원인

후보 총계가 이상했다. 112건 × 최대 20개면 2,240개까지 가능한데 **273개**뿐이었다.
임계값(`EMBEDDING_MIN_SCORE=0.6155`)을 통과하는 후보가 그만큼 적다는 뜻이라 따로 셌다.

**임계 통과 후보 수 분포 (확대 112건)**

| 후보 수 | 케이스 |
|---:|---:|
| **0개** | **43건 (38%)** |
| 1개 | 31건 |
| 2개 | 11건 |
| 3~4개 | 12건 |
| 5개 이상 | **15건 (13%)** |

케이스당 평균 **2.44개**다.

**즉 Top-5 가 Top-3 보다 나아질 수 있는 케이스가 112건 중 15건뿐이다.**
Top-3 = Top-5 는 순위 문제도, 중복 문제도 아니고 **후보가 애초에 없어서**다.

이 진단은 앞선 두 가설을 모두 기각한다.
- 8/11 "리랭커로는 이 구간이 안 움직인다" → **맞다. 다만 이유가 재순위가 아니라 후보 부재다.**
- 8/12 "중복이 후보를 채우고 있을 수 있다" → **아니다. NIA 는 후보에 아예 없다.**

**남는 방향은 하나다: 대조할 문서를 늘리는 것(수집).**
임계값을 낮추는 방법은 지시대로 선택지에 넣지 않는다 — 잘못된 근거 제시가 늘어난다.

# 2부 — 수집 경로 3종 조사

**은행연합회는 `Disallow: /` 라 제외했다. 우회하지 않았다.**
금감원·경찰청 직접 크롤링도 하지 않았다.

## 경로 ③ counterscam112.go.kr — **가장 유망. 경찰청 직접 수집의 대체재가 된다**

| 항목 | 내용 |
|---|---|
| robots.txt | `User-agent: *` / `Allow: /` ✅ |
| **이용 조건** | **공공누리 제1유형** (출처표시). 경찰청 저작권정책 페이지에서 확인 |
| 현재 보유 | **46건** (`bbs003` 피싱 예·경보 22 + `bbs002` 보도자료 24) |
| 게시물 번호 범위 | 보유분 `pstSn=1~315` |
| 갱신 주기 | 최신글 2026-08-10 · 7~8월에만 3건 이상 → **월 2~4건 추정** |
| 신청 필요 | **없음** |
| 소요 기간 | 즉시 (재수집만 하면 됨) |

**추가 확보 가능량**: `pstSn` 이 315까지 존재하는데 46건만 갖고 있다.
두 게시판 합쳐 **최소 3페이지 이상**이 확인됐고, 미수집분이 상당하다.
정확한 총량은 페이지네이션이 총건수를 안 보여줘 **확인 못 했다** — 수집하며 세야 한다.

**단서 하나**: 저작권정책이 *"공공누리 표시가 부착된 저작물인지를 확인한 이후에
자유롭게 이용하시기 바랍니다"* 라고 적고 있다. 일괄 허용이 아니라 **문서별 표시 확인**이
전제다. 수집 시 게시물별 공공누리 표시 유무를 함께 기록해야 한다.

> ★ 기존 46건의 `license` 필드가 전부 `"공식 사이트 저작권정책 확인 필요"` 로 남아 있다.
> 이번에 제1유형으로 확인됐으니 **기존 46건의 라이선스 필드도 함께 갱신**해야 한다.

## 경로 ① 공공데이터포털 data.go.kr — **이용 조건은 가장 안전하나, 쓸 자료가 아니다**

"보이스피싱" 검색 **28건**. 이용허락범위는 전부 "공공"이라 조건은 깨끗하다.
그런데 상위 8건이 이런 성격이다.

| 데이터셋 | 제공기관 | 유형 |
|---|---|---|
| 경찰청__보이스피싱 현황 | 경찰청 | 파일데이터 |
| 경찰청_전화금융사기__보이스피싱 시도청별 피해금액 현황 | 경찰청 | 파일데이터 |
| 보이스피싱 예방 동영상 | 인천청·전북청 | 파일데이터 |
| 뉴스빅데이터 메타데이터 | 언론진흥재단 | 파일데이터 |

**전부 통계표·동영상·메타데이터다. 사기 경보문도 제도 안내문도 아니다.**

★ 이건 방금 1부에서 확인한 것과 정확히 같은 성격이다 —
**NIA 297건(통계 보고서)이 검색 기여 0%인 이유가 그것이다.**
같은 종류를 더 넣으면 코퍼스만 커지고 검색은 그대로다.

**판단: 이용 조건은 가장 안전하지만 지금 필요한 자료가 없다.
"안전한 경로"라는 기대와 달리 우선순위가 가장 낮다.**
(통계는 나중에 기관 대시보드·리포트 용도로는 쓸 수 있다.)

**금융감독원 제공 데이터셋**은 기관 필터 조회가 되지 않아 **확인 못 했다**.

## 경로 ② 금융감독원 오픈 API — **사기 경보문 API 는 없다**

`/fss/main/contents.do?menuNo=200269` 에서 확인한 제공 API **10종**:

> 금융꿀팁 200선 · 금융소비자 뉴스 · 보도자료 · 금융권 채용정보 · 금융시장동향 ·
> 금융감독정보 · 금융감독제도 일반 · 분야별 감독제도 · 은행 경영통계 · 외국인 국내 투자동향

**소비자경보·보이스피싱 전용 API 는 목록에 없다.**

간접 후보 2개는 있다.
- **보도자료 API** — 금융위 보도자료와 같은 성격이면 3분류의 **C(정책·성과 발표)** 가 다수일 것이다
- **금융꿀팁 200선 API** — 제목상 **A(제도 안내문)** 에 가장 가깝다. 실제 내용 확인 필요

| 항목 | 내용 |
|---|---|
| 신청 필요 | **있다** — 인증키 신청 (`/fss/api/apiKey/forInsert.do?menuNo=200273`) |
| 승인 소요 기간 | **명시 없음. 확인 못 했다** |
| 이용 조건 | **확인 못 했다** (저작권정책 본문이 JS 라 미로드) |

**★ 신청은 사람이 해야 한다.** 계정 생성과 인증키 신청은 제가 하지 않는다.
