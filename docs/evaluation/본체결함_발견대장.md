# 본체 결함 발견 대장

> **실험 파일에서 본체(`services/`·`routers/`)의 결함을 우회했다면, 우회 코드만 남기지 말고
> 여기에 올린다.** 우회는 그 파일에서만 유효하고, 본체는 그대로 라이브에 나간다.

## 왜 이 문서가 생겼나

`api/experiments/score_questions.py` 가 2026-08-05 에 이렇게 적었다.

```python
# ★ 도메인·소수점의 마침표를 문장 구분자로 세지 않는다(2026-08-05).
#   프로덕션 count_sentences() 는 마침표를 무조건 구분자로 보기 때문에
#   "정부 기관 주소(go.kr)와 다릅니다." 같은 정상적인 1문장을 2문장으로 센다.
#   ※ 프로덕션 코드는 건드리지 않고, 채점 시 LLM·규칙 양쪽에 똑같이 적용한다.
#     프로덕션에도 같은 문제가 있다는 사실은 보고서에 남긴다.
```

**정확한 진단이었다. 그리고 우회만 남았다.**
12일 뒤(2026-08-16) 그 결함이 라이브 사고가 됐다 — 도메인 두 개를 비교하는 질문이
4문장으로 세어져 재생성 3회가 모두 막히고, 폴백의 거짓 전제가 사칭 문자에서
"있으니 괜찮다"로 읽혔다.

★ 우회는 **발견을 소비해 버린다.** 실험은 통과하니 아무도 다시 보지 않는다.

## 규칙

1. 실험·벤치 파일에서 본체 동작을 우회했다면 **이 문서에 항목을 추가한다.**
2. 항목에는 최소한 이것을 적는다 — 발견일 · 어느 파일이 우회했나 · 본체의 어느 함수/상수인가
   · 우회하지 않으면 무엇이 잘못되나 · 실제 사용자에게 어떻게 나타날 수 있나.
3. 우회 코드 주석에 이 문서를 링크한다.
4. 본체를 고치면 상태를 `해결`로 바꾸고 고친 커밋을 적는다. **항목을 지우지 않는다.**

★ "보고서에 남긴다"는 문장은 충분하지 않다. 보고서는 그날 읽히고 덮인다.
  이 문서는 **미해결 목록**이라 남아 있는 한 계속 보인다.

## 유형 (개별 항목보다 먼저 읽을 것)

### L1. 새 방식을 넣을 때 옛 방식을 끄지 않으면, 옛 방식이 조용히 오답을 만든다

`근거_검증표`(match_evidence)는 **2026-07-28**, 벡터 검색이 없던 시절의 유일한 근거
대조 장치였다. **2026-08-01** 하이브리드 검색, **08-05** 로컬 임베딩이 들어왔는데
옛 경로는 그대로 남았다. 그 뒤 **20일간**, 키워드 한 개(`이용`·`정보`·`대한`)만 겹쳐도
무관한 통계가 근거로 붙었다. 하나카드 광고에 "70대 이상 디지털정보화 수준"이 붙는 식이다.

★ 2026-08-06 에 이 문제가 **절반만** 고쳐진 흔적도 있다 — `has_confident_source` 에서는
빼면서(주석에 `"이용" → NIA` 를 정확히 적어 뒀다) `references` 와 신호에는 남겼다.
증상을 눌렀고 경로는 남긴 것이다.

**규칙**: 검색·매칭 방식을 새로 넣을 때는 **옛 경로를 어떻게 할지 같은 커밋에서 정한다.**
끄든, 남기든, 남긴다면 왜 남기는지 적는다. 그냥 두면 아무도 다시 보지 않는다.

### L2. 컨테이너 안 경로에 쓴 파일은 기본적으로 사라진다

백업·기준 기록을 `Path(__file__).parents[...]` 로 잡으면 컨테이너에서는 마운트되지 않은
경로(`/docs`·`/deploy`)가 되고, 컨테이너를 다시 만들면 없어진다.

- 2026-08-17 `tools/delete_rows.py` 백업이 `/docs` 로 갔다 (첫 실행에서 발견)
- 2026-08-19 `tools/regression_check.py` 기준 파일이 `/deploy` 로 갔다 — **하루 만에 반복**

★ 후자가 더 나쁘다. 기준 파일이 사라지면 매 실행이 "기준 기록 생성"으로 시작해
**영원히 실패하지 않는 검사**가 된다. 아무것도 검사하지 않는 초록불이다.

**규칙**: 컨테이너에서 파일을 쓸 때는 `/app/data/` 처럼 **마운트가 확인된 경로**만 쓴다.
쓴 뒤에 **호스트에서 보이는지 눈으로 확인**한다.

### L3. 임계값이 없는 경로는 "방어선이 무엇인지" 를 적어 둬야 한다

판정에 관여하지만 **임계값이 아예 없는** 경로가 6종 있다(2026-08-19 전수 조사).
조건에 걸리면 그냥 붙는다.

| 경로 | 판정 방식 | 무엇이 방어선인가 |
|---|---|---|
| `detect_signals` | SIGNAL_RULES 3종 — 키워드 포함 여부만 | **없음** — 어휘가 늘면 오탐이 는다 |
| 위험행동 | RISK_ACTION_KEYWORDS 4유형 — 최장매칭 | 문맥조건 |
| 경보문 판정 | `data_type=warning_case` + 사람 검수 id 8건 | 사람 검수 |
| 기관 도메인 대조 | 매핑표 31곳 — 문자열 일치/불일치 | 침묵 규칙 3개 |
| 주소 펼치기 | MAX_HOPS=3 · TIMEOUT=3.0 (임계값 아님) | 없음 |
| 발행기관 명시 | `_ORG_SUFFIX_RE` 정규식 일치 | info 신호라 tier 영향 없음 |

★ **임계값이 없다는 것 자체는 결함이 아니다.** 위 넷은 다른 방어선을 갖고 있다.
  다만 그 방어선이 무엇인지 적어 둔다 —
  **없다고 착각하고 어휘만 늘리면 그때 뚫린다.**

★ 이 표는 지우지 않는다. `detect_signals` 에 단어를 하나 더 넣기 전에 이 줄을 먼저 읽는다.
  방어선이 "없음"인 두 줄이 어휘 보강(#43)이 실제로 닿는 곳이다.

### 1. 문장 세기가 도메인·소수점의 점을 문장 끝으로 센다

- **우회**: `score_questions.py` 가 채점 전에 도메인/소수점의 `.` 을 안전 문자로 바꿔서 셌다.
- **본체**: `services/prompt_chain.py` 의 `_SENTENCE_SPLIT_RE = re.compile(r"[.!?。？！]+")`
- **우회하지 않으면**: `"받으신 주소 a.com과 공식 주소 b.or.kr을 비교해 보셨나요?"`(1문장)이
  **4문장**으로 세어진다. 상한이 2라 `too_long` 으로 차단된다.
- **사용자에게 어떻게 나타났나**: 도메인 두 개를 비교하게 하는 질문 — 사칭 문자에 줄 수 있는
  가장 좋은 질문 — 이 구조적으로 통과 불가였다. 재생성 3회가 모두 막혀 폴백으로 내려갔고,
  폴백 문장이 "기관 이름이 보이지 않는다면"을 하드코딩하고 있어서, 기관명이 적힌 사칭
  문자에서 **안심시키는 방향으로** 작동했다. 2026-08-16 라이브에서 실제로 발생.
- **해결**: 보호 치환 도입(2026-08-18). 폴백률 2.7% → 0.9%, `too_long` 폴백 0건.
  경위: [`docs/reports/2026-08-18_문장세기_수정_실험가드_NIA링크.txt`](../reports/2026-08-18_문장세기_수정_실험가드_NIA링크.txt)

## 미결 항목 (결함은 아니지만 결론을 못 낸 것)

### M1. 질문의 (가) 방향 — 입력에 없는 것을 있다고 전제 · 잔여 2건

- **상태**: **미결. 지금 결론 내지 않는다** (2026-08-19 사람 결정)
- **무엇**: `services/question_check.py` 의 (가) 검사에서 확대 112건 중 13건이 걸리는데,
  그중 11건은 **평가셋이 요약문이라서** 생긴 것이고 진짜는 2건(B18 · R09)이다.
- **왜 지금 못 재나**: 확대 평가셋의 문장은 실제 문자가 아니라 요약이다.
  예) S14 `"긴급재난지원금 신청이 오늘 마감됩니다. 아래 주소에서 …"` — **"아래 주소"라고
  말만 하고 실제 URL 이 없다.** 진짜 문자였다면 주소가 있었을 것이고 질문은 옳다.
  실측: 112건 중 주소가 실재하는 건 10건, 전화번호가 실재하는 건 **2건**뿐이다.
  → 이 표본으로는 (가)의 실제 발생률을 잴 수 없다. 숫자를 내면 과대 계상된다.
- **언제 다시 재나**: 팀이 모으는 **스팸함 문자 표본이 도착하면** 그때 다시 잰다.
  (개인정보 제거 → 원문 보존 → 평가셋·어휘 원천으로만 사용, 검색 코퍼스에 넣지 않는다.)
- **그때까지**: `question_check` 의 (가) 검사는 **파이프라인에 연결하지 않는다.**
  (나) 방향은 원인이 폴백 문장이었고 이미 해결됐다(2026-08-17, `8d82633`).
- 근거: [`docs/reports/2026-08-17_질문폴백_근거문구_마스킹경계.txt`](../reports/2026-08-17_질문폴백_근거문구_마스킹경계.txt)

### M2. NIA 통계 근거가 무관한 문자에 붙는다

- **상태**: **해결** (2026-08-20) — `search.EVIDENCE_TABLE_AS_REFERENCE = False` 로 경로를 껐다.
  CSV·적재는 그대로 둔다(지우지 않았다). True 로 되돌리면 즉시 복귀한다.
  실측: verdict_hint 변화 **0건**(112·30·11 전수) · render_verdict 142건 **tier 변화 0** ·
  사칭 건 변화 **0건**. 정상 3건이 "같은 안내인지 확인하지 못했어요" → "공식 자료를
  못 찾았어요"로 바뀐다(tier 는 hold 그대로).
- **유형**: L1 (새 방식을 넣고 옛 방식을 안 끔)
- **무엇**: `corpus_index.match_evidence(min_score=1)` 이 키워드 한 개만 겹쳐도
  `근거_검증표.csv` 의 통계를 근거로 붙인다. 그 표 11건 중 **10건이 NIA 한 URL** 이라,
  카드 광고·관절염 수술비 안내 같은 무관한 글에 같은 링크가 반복해서 나간다.
  실사용 11건 중 3건, 확대 112건 중 8건. 실제 사용자 세션에서도 재현됐다.
- **왜 아직 안 고쳤나**: 임계값 변경이라 "실패를 보고 임계값을 만지지 않는다"는 원칙과
  충돌하는지 사람이 먼저 봐야 한다.
- ★ **`survey_report` 제외 승인은 2026-08-19 에 취소됐다** — 대상이 다른 경로라 효과가 0이다.
  대장만 보고 "승인은 났는데 안 했네"로 읽히면 안 되므로 여기 적어 둔다.
- **2026-08-19 조사 결과**: 이 경로가 근거를 붙이는 건 실사용 11건 중 3건 · 확대 112건 중
  10건. 겹친 단어가 `20`·`2025`·`이상`·`대한`·`이용`·`정보` — **10건 중 9건이 순전한 오답**이고
  나머지 1건(N11)도 확인 근거로는 쓸 수 없다. 코퍼스로 옮길 만한 것은 없다.
  → 제안은 "임계값 상향"이 아니라 **경로를 끄는 것**. 적용 전이다.

### M3. 하한선 재측정 시점이 규칙으로 없다

- **상태**: **해결** (2026-08-20) — 매일 도는 회귀 검사에 코퍼스 규모 감시를 넣었다.
  `tools/regression_check.py` 가 `official_docs`·`official_chunks`·`scam_cases` 를 기록하고
  직전 실행과 다르면 **"하한선 재측정 필요"로 실패 처리**한다(종료코드 1).
  ★ 기준 파일은 사람이 재측정한 뒤 직접 갱신한다 — 자동으로 덮으면 경고가 한 번 찍히고
    조용히 사라진다.
  ★ 실패해야 할 때 실패하는지 확인했다: 기준을 1052 로 되돌리자 FAIL·종료코드 1.
- **★ 1회 재측정 결과 (2026-08-19)**: `_OFFICIAL_MIN_SCORE=12.0` 의 위치가 **어긋났다.**
  무관한 문장 "오늘 날씨가 좋네요" 의 BM25 최고점이 **12.180** 으로 임계값을 넘는다
  (원래 노이즈 바닥 4.9~10.6). 다만 이 임계값은 **임베딩이 실패해 BM25 로 폴백할 때만**

- **원래 무엇이었나**: `_OFFICIAL_MIN_SCORE=12.0`(BM25)과 `match_scam_cases min_score=5.0`
  (IDF류)은 **코퍼스가 바뀌면 의미가 이동한다.** 실측:
- **무엇**: `_OFFICIAL_MIN_SCORE=12.0`(BM25)과 `match_scam_cases min_score=5.0`(IDF류)은
  **코퍼스가 바뀌면 의미가 이동한다.** 실측:

- **문제였던 것**: "코퍼스가 바뀌면 다시 실측하라"가 **코드 주석에만** 있었다.

  임계값을 넘었다. **규칙이 주석에만 있으면 지켜지지 않는다.**
