# 본체 결함 발견 대장

> **실험 파일에서 본체(`services/`·`routers/`)의 결함을 우회했다면, 우회 코드만 남기지 말고
> 여기에 올린다.** 우회는 그 파일에서만 유효하고, 본체는 그대로 라이브에 나간다.

## 왜 이 문서가 생겼나

`api/experiments/score_questions.py` 가 2026-08-05 에 이렇게 적었다.

```python
# ★ 도메인·소수점의 마침표를 문장 구분자로 세지 않는다(2026-08-05).
#   프로덕션 count_sentences() 는 마침표를 무조건 구분자로 보기 때문에
#   "정부 기관 주소(go.kr)와 다릅니다." 같은 정상적인 1문장을 2문장으로 센다.
#   ※ 프로덕션 코드는 건드리지 않고, 채점 시 LLM·규칙 양쪽에 똑같이 적용한다.
#     프로덕션에도 같은 문제가 있다는 사실은 보고서에 남긴다.
```

**정확한 진단이었다. 그리고 우회만 남았다.**
12일 뒤(2026-08-16) 그 결함이 라이브 사고가 됐다 — 도메인 두 개를 비교하는 질문이
4문장으로 세어져 재생성 3회가 모두 막히고, 폴백의 거짓 전제가 사칭 문자에서
"있으니 괜찮다"로 읽혔다.

★ 우회는 **발견을 소비해 버린다.** 실험은 통과하니 아무도 다시 보지 않는다.

## 규칙

1. 실험·벤치 파일에서 본체 동작을 우회했다면 **이 문서에 항목을 추가한다.**
2. 항목에는 최소한 이것을 적는다 — 발견일 · 어느 파일이 우회했나 · 본체의 어느 함수/상수인가
   · 우회하지 않으면 무엇이 잘못되나 · 실제 사용자에게 어떻게 나타날 수 있나.
3. 우회 코드 주석에 이 문서를 링크한다.
4. 본체를 고치면 상태를 `해결`로 바꾸고 고친 커밋을 적는다. **항목을 지우지 않는다.**

★ "보고서에 남긴다"는 문장은 충분하지 않다. 보고서는 그날 읽히고 덮인다.
  이 문서는 **미해결 목록**이라 남아 있는 한 계속 보인다.

### 1. 문장 세기가 도메인·소수점의 점을 문장 끝으로 센다

- **우회**: `score_questions.py` 가 채점 전에 도메인/소수점의 `.` 을 안전 문자로 바꿔서 셌다.
- **본체**: `services/prompt_chain.py` 의 `_SENTENCE_SPLIT_RE = re.compile(r"[.!?。？！]+")`
- **우회하지 않으면**: `"받으신 주소 a.com과 공식 주소 b.or.kr을 비교해 보셨나요?"`(1문장)이
  **4문장**으로 세어진다. 상한이 2라 `too_long` 으로 차단된다.
- **사용자에게 어떻게 나타났나**: 도메인 두 개를 비교하게 하는 질문 — 사칭 문자에 줄 수 있는
  가장 좋은 질문 — 이 구조적으로 통과 불가였다. 재생성 3회가 모두 막혀 폴백으로 내려갔고,
  폴백 문장이 "기관 이름이 보이지 않는다면"을 하드코딩하고 있어서, 기관명이 적힌 사칭
  문자에서 **안심시키는 방향으로** 작동했다. 2026-08-16 라이브에서 실제로 발생.
- **해결**: 보호 치환 도입(2026-08-18). 폴백률 2.7% → 0.9%, `too_long` 폴백 0건.
  경위: [`docs/reports/2026-08-18_문장세기_수정_실험가드_NIA링크.txt`](../reports/2026-08-18_문장세기_수정_실험가드_NIA링크.txt)

## 미결 항목 (결함은 아니지만 결론을 못 낸 것)

### M1. 질문의 (가) 방향 — 입력에 없는 것을 있다고 전제 · 잔여 2건

- **상태**: **미결. 지금 결론 내지 않는다** (2026-08-19 사람 결정)
- **무엇**: `services/question_check.py` 의 (가) 검사에서 확대 112건 중 13건이 걸리는데,
  그중 11건은 **평가셋이 요약문이라서** 생긴 것이고 진짜는 2건(B18 · R09)이다.
- **왜 지금 못 재나**: 확대 평가셋의 문장은 실제 문자가 아니라 요약이다.
  예) S14 `"긴급재난지원금 신청이 오늘 마감됩니다. 아래 주소에서 …"` — **"아래 주소"라고
  말만 하고 실제 URL 이 없다.** 진짜 문자였다면 주소가 있었을 것이고 질문은 옳다.
  실측: 112건 중 주소가 실재하는 건 10건, 전화번호가 실재하는 건 **2건**뿐이다.
  → 이 표본으로는 (가)의 실제 발생률을 잴 수 없다. 숫자를 내면 과대 계상된다.
- **언제 다시 재나**: 팀이 모으는 **스팸함 문자 표본이 도착하면** 그때 다시 잰다.
  (개인정보 제거 → 원문 보존 → 평가셋·어휘 원천으로만 사용, 검색 코퍼스에 넣지 않는다.)
- **그때까지**: `question_check` 의 (가) 검사는 **파이프라인에 연결하지 않는다.**
  (나) 방향은 원인이 폴백 문장이었고 이미 해결됐다(2026-08-17, `8d82633`).
- 근거: [`docs/reports/2026-08-17_질문폴백_근거문구_마스킹경계.txt`](../reports/2026-08-17_질문폴백_근거문구_마스킹경계.txt)

### M2. NIA 통계 근거가 무관한 문자에 붙는다
