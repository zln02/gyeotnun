## 3. ★ 적재 전에 반드시 해야 하는 것 (지금 하지 않았다)

### (1) B 를 `SCAM_CASES` 에 넣으면 IDF 척도가 이동한다

`_keyword_weight = log((N+1)/(df+1)) + 1` 이라 `SCAM_CASES` 가 늘면 **모든 점수가
함께 올라가는데** 하한선 `min_score=5.0` 은 절대값이라 따라가지 않는다.
어제 재확인한 그대로다 — N=51→185 에서 정상 최고점이 6.72→14.58 로 뛰었다.

- 하한선 결정(`하한선_결정_2026-08-13.md`)은 **"N=51 에서의 5.0"** 을 유지한 것이다.
- 적재하면 `test_scam_corpus_size_is_recorded` 가 즉시 실패한다. **그게 정상 동작이다.**
- 절차: `exp_scam_min_score_tradeoff.py` 재측정 → `docs/evaluation/` 기록 → 결정 갱신.

### (2) B 를 `OFFICIAL_DOCS` 에 넣는 경우에도 BM25 폴백을 재측정해야 한다

`_OFFICIAL_MIN_SCORE = 12.0` 도 절대값이고 BM25 점수는 코퍼스 크기를 탄다
(`본선과제_BM25폴백_척도이동.md`). 임베딩(코사인)은 크기와 무관해 안전하지만,
**폴백 경로는 안전하지 않다.**

### (3) 경보문으로 쓸 것은 `ALERT_DOC_IDS` 문서 id 허용목록에 넣는다

`data_type` 으로 뭉뚱그리지 않는다. 오늘 press_release 24건에 적용한 방식 그대로다
(`press_release_24건_분류초안_2026-08-13.md` §4).

### (4) 오래된 문서(2005–2014, 30건)를 그대로 넣지 않는다

제도·수법이 지금과 다르다. 사람이 검토표에서 거른다.

## 4. 이용 조건 — ★ 공공누리 유형이 표시돼 있지 않다

`https://www.fsc.go.kr/ut020104` (저작권정책) 원문 요지:

1. 저작권법 제24조의2에 따라 **금융위가 저작재산권 전부를 보유한 저작물은 자유이용 가능**
2. **수익을 얻거나 이에 상응하는 혜택을 누리려면 사전 협의·허락이 필요하고,
   허락받더라도 출처가 금융위임을 명시해야 한다**
3. **저작권 전부를 갖지 않은 자료도 섞여 제공된다.** 그런 자료는 단순 열람 외
   무단 변경·복제·배포·개작이 금지된다

조사 단계에서 "공공누리 마크 확인, 유형 미확인"이라고 적었던 부분을 다시 봤다.
페이지의 `kogl.or.kr` 링크는 **OPEN 정보공개 배너**이고 공공누리 유형 표시가 아니다.
**제1~4유형 어느 것도 명시돼 있지 않다.**

### 그래서 지금 지키는 것

| | |
|---|---|
| 출처 표시 | 곁눈은 근거를 항상 기관명 + 원문 URL 로 보여준다. 이미 지키고 있다 |
| 비영리 | 현재 해커톤 프로젝트다. **서비스화하면 2항이 걸린다** — 그때 사전 협의가 필요하다 |
| 첨부파일 | **받지 않았다.** 목록(파일명·URL)만 기록했다. 3항의 공동저작 위험이 첨부에 몰려 있다 |
| 원문 저장소 반영 | **하지 않는다.** `corpus/collect/*.jsonl` 을 `.gitignore` 에 넣었다 — 공개 저장소에 원문을 올리지 않는다. 스크립트로 언제든 재현된다 |

> ★ 이건 "확인 못 함"이 아니라 **"명시돼 있지 않음"** 이다. 둘은 다르다.
>   유형이 필요하면 금융위에 직접 문의해야 한다. 추정해서 쓰지 않는다.
