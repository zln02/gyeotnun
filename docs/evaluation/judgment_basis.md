## ★ 핵심 답변 — (a) 로 판정된 건은 **0건**이다

> **곁눈은 "근거 대조"를 한다고 서술하면서, 실제로는 근거 대조를 하지 않는다.**
> 하는 일은 (1) 위험 신호 탐지와 (2) 유사도 검색 두 가지뿐이다.

| 원인 | 건수 | 케이스 |
|---|---|---|
| (a) 근거 문서와 **내용이 불일치**해서 | **0건** | 없음 |
| (b) 위험 신호가 검출돼서 | 14건 | S01·S02·S04·S05·S06·S09·S10·B01·B03·B05·B06·B08·B09·B10 |
| (c) 근거를 못 찾아서 | 3건 | S03·S07·S08 |
| (d) 기타 | 13건 | N01~N10·B02·B04·B07 |

### 0건인 이유는 우연이 아니라 구조다

`collect_evidence()` 에 **두 텍스트의 내용을 비교하는 코드가 존재하지 않는다.**
판정 분기는 네 개뿐이다(`api/services/search.py:365-382`):

```python
if not refs:                    hint = "no_source_found"     # (c) 근거 없음
elif risky:                     hint = "partially_matched"   # (b) attention 신호
elif not has_confident_source:  hint = "no_source_found"     # 유사도가 낮음
else:                           hint = "needs_check"         # 그 외
```

- 찾은 문서는 **판정에 관여하지 않는다.** `official_source_found` 는
  `severity="info"` 라 `risky` 계산에서 제외된다.
- 문서가 하는 일은 두 가지뿐이다 — `references` 목록에 들어가는 것,
  그리고 유사도 점수가 임계값을 넘는지 보는 것.
- 유사도가 낮을 때 나오는 판정은 "불일치"가 아니라 **"확인 불가"** 다.
  즉 *찾지 못했다* 는 말이지 *다르다* 는 말이 아니다.

**"이 문서에는 65세 이상이라고 적혀 있는데 이 문자에는 60세라고 적혀 있다"**
같은 판단은 지금 시스템 어디에서도 일어나지 않는다.

## 3. 사칭 10건 — "공식 절차와 다름"을 인지하는가

**인지하지 못한다.** 단순히 신호만 잡는다.

S04 `국민연금 추가 지급 대상. 신분증 사진을 카카오톡으로 보내면 즉시 접수됩니다.`

| 시스템이 한 일 | 시스템이 하지 않은 일 |
|---|---|
| 사기 사례 2건과 어휘 중첩 검출 | "국민연금공단은 카카오톡으로 신분증을 받지 않는다"는 사실 확인 |
| 판정 = 의심 | 공식 접수 절차가 무엇인지 조회 |

찾은 문서도 「기초연금」 같은 제도 소개 문서이지, **접수 절차 규정**이 아니다.
코퍼스에 "정상 절차가 무엇인가"를 담은 문서가 없으므로, 있다 해도 비교할
로직이 없다(§1 참고).

즉 S04 를 잡아낸 근거는 *"공식 절차와 다르다"* 가 아니라
*"개인정보 요구 어휘가 사기 사례와 겹친다"* 다.

## 4. 훈련 카드에 무엇이 저장되는가

`api/routers/training.py` · `api/services/rag.py` · `api/models/schemas.py`
· `corpus/training_cards/sample_cards.json` 확인 결과.

### ★ 전제부터 다르다 — 훈련 카드는 사용자 이력에서 만들어지지 않는다

지시서는 "놓친 질문이 저장되는가"를 물었지만, **저장 여부 이전에 그런
파이프라인이 없다.** 훈련 카드는 사용자가 무엇을 놓쳤는지와 무관하게
`corpus/training_cards/sample_cards.json` 의 **고정 카드 3장** 중에서 고른다.

```python
# api/services/rag.py:41
def pick_today_card(error_type):
    cards = load_sample_cards()          # 고정 JSON 3장
    if error_type:
        for c in cards:
            if c.get("target_error_type") == error_type:
                return c
    return cards[0]                      # 못 찾으면 무조건 첫 장
```

사용자 이력에서 카드를 만드는 함수(`generate_card_from_corpus`)는
**미구현이다** — `raise NotImplementedError`.

| 항목 | 실제 |
|---|---|
| 놓친 질문이 저장되는가 | **저장 안 됨.** 카드는 이력과 무관한 고정 샘플이다 |
| 개인화 요소 | `target_error_type` 문자열 매칭 **하나뿐** (카드 3장 중 고르기) |
| 그 질문의 "정답"이 함께 저장되는가 | 해당 없음. 다만 카드에는 `answer` + `explanation` 이 **미리 적혀 있다** |
| 근거 URL | 카드 JSON 에는 `source_url` 이 **있다**. 그러나 `TrainingCardResponse` 스키마에 그 필드가 없어 **API 응답에서 탈락한다** |

`/checks/{id}/verdict` 가 태깅한 `error_type` 도 응답으로만 돌려주고
어디에도 **저장하지 않는다**(`_MEMORY_STORE` 는 읽기만 한다). 다음 세션에
그 유형을 다시 쓰려면 클라이언트가 들고 있어야 한다.

### 사용자가 훈련 카드에서 실제로 보는 것

고정 카드 3장 중 1장의 지문·보기·정답·해설. 예:

```
(가) 65세 이상이면 누구나 매달 40만원을 받습니다.
(나) 65세 이상 중 소득인정액이 기준액 이하인 분이 기초연금을 받습니다.
→ 정답 (가) / 해설: '누구나·전원·무조건' 같은 말이 보이면 …
```

**자기가 방금 놓친 그 문자에 대한 복습은 아니다.** 그리고 카드 JSON 에
`source_url`(https://basicpension.mohw.go.kr/)이 들어 있는데도 스키마에서
빠져 화면까지 가지 못하므로, 사용자는 **근거 원문으로 돌아갈 수 없다.**

## 5. 종합 — 기획서 문구를 고쳐야 한다

현재 곁눈이 실제로 하는 일:

1. **위험 신호 탐지** — 키워드 규칙 3종 + 사기 사례 어휘 중첩
2. **유사 문서 검색** — 임베딩 유사도, 임계값 이상이면 "확인됨"

하지 않는 일:

- 찾은 문서와 입력 내용의 **사실 대조**
- 공식 절차와의 **차이 판별**

> "근거 대조" 라는 표현은 현재 구현을 정확히 기술하지 않는다.
> **"공식 자료 검색 + 위험 신호 탐지"** 가 맞는 서술이다.

이 문서는 현재 상태 기술이 목적이므로 코드를 고치지 않았다.
단, §1 에서 원인이 특정된 `match_scam_cases()` 오탐은 별도 지시로
수정했다 → `docs/evaluation/scam_matching_fix.md`

## ②-보조 '근거 유보 한 줄' — 왜 필요했나 (2026-08-17 채택)

★★ **의심 신호가 사실 한 줄을 이기면 유보 문구가 사라진다 — 하필 사칭 건에서.** ★★

이번 진단의 핵심이다. `factBlock()` 은 **한 줄만** 고르는 구조라, 우선순위가 이렇다.

```
① official_alert_matched  →  "비슷한 사례를 알리는 공식 안내가 있어요"
② similar_scam_case       →  "이전에 확인된 사례와 비슷한 문장이 있어요"
③ 그 밖의 attention 신호
④ 근거 있음 + 확신 아님    →  "같은 안내인지는 확인하지 못했어요 · 원문 …"   ← 유보
⑤ 근거 없음               →  "공식 자료를 못 찾았어요"
⑥ 확신 매칭               →  "원문 보기 → …"
```

④가 유보 문구인데, ①②③가 있으면 **④까지 내려오지 않는다.** 그런데 ①②③가 붙는
글은 대체로 **사칭**이다. 즉 유보가 가장 필요한 자리에서 유보가 사라진다.

실측 (2026-08-16, 유사도 하한 0.6155 ~ 확신 0.6790 구간)

| 사례 | 유사도 | 사실 한 줄 | 유보 |
|---|---|---|---|
| S25 | 0.6295 | 같은 안내인지는 확인하지 못했어요 · 원문 bokjiro.go.kr | 붙는다 |
| S31 | 0.6308 | 같음 | 붙는다 |
| S01 | 0.6644 | 이전에 확인된 사례와 비슷한 문장이 있어요 | **빠진다** |
| 라이브 | 0.6539 | 같음 | **빠진다** |

참고자료 목록에는 다른 제도의 공식 문서(`의료급여수급권자 일반건강검진비 지원` 등)가
그대로 보이는데, "같은 안내인지 확인하지 못했다"는 말만 없어진다.
