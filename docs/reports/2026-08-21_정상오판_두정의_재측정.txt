1. 무엇을 잘못 인용했나
=======================

  bench_eval_120.py 의 지표를 그대로 가져다 "정상 문자를 의심으로 표시"라는
  행 이름을 붙였습니다. 그런데 그 스크립트가 세는 것은 이것입니다.

      bench_eval_120.py:96   risky = any(s.get("severity") == "attention" for s in res.signals)
      bench_eval_120.py:117  misjudged = (row["기대판단"] == "정상") and risky

  즉 **`severity == "attention"` 신호가 하나라도 붙었는가**이고,
  **화면 tier 와 무관합니다.** 스크립트 주석도 그렇게 적고 있습니다
  ("(2) 오판없음 = 위험 경고를 띄우지 않았는가").

  화면은 신호를 그대로 쓰지 않습니다. `web/src/verdict.js` 의
  **ATTENTION_KEYS 허용 목록**을 통과한 신호만 단계를 올립니다.

      ATTENTION_KEYS = similar_scam_case · urgency_pressure ·
                       condition_omitted · official_alert_matched

  → 신호 기준 11건, 화면 기준 2건. **그 차이 9건이 허용 목록이 막은 것**입니다.

  ★ 제가 붙인 행 이름("의심으로 표시")은 화면을 가리키는데 숫자는 신호였습니다.
    행 이름과 숫자가 다른 것을 재고 있었습니다.


2. 측정 방법 (화면 기준)
========================

    docker compose exec api python3 experiments/dump_screen_payloads.py now
    docker compose cp api:/app/data/screen_now.json /tmp/
    node tools/render_verdict.mjs /tmp/screen_now.json /tmp/render_now.json

  verdict.js 를 실제로 돌려 tier 를 뽑습니다. 142건 전수.
  tier 사다리: danger > warn > act > hold > ok

      신 정의 = tier ∈ {warn, danger}
      구 정의 = tier ∈ {warn, danger, act}

  ★ act 를 따로 두는 근거는 verdict.js:87 에 있습니다 —
    "그래서 tier 'act' 를 따로 두고 색·그림도 경고(빨강)가 아닌 주황을 쓴다."

  ── 확대112:R10   tier=act    기대=정상   위험행동=인증번호     ← 구 정의에만 포함

6. README 조치
==============

  지시대로 한 숫자로 두지 않고 **두 줄**로 적었습니다.

      | 정상 문자를 **사기 의심**으로 표시        | 1/37 (2.7%) | 1/10 (10.0%) |
      | 정상 문자에 **경고 계열 화면**(행동 포함) | 2/37 (5.4%) | 1/10 (10.0%) |

  그리고 아래 세 가지를 본문에 적었습니다.
    · act 는 "사기입니다"가 아니라 "인증번호를 넣기 전에 한 번 보세요"라는 것
    · 세 건의 정체(앱설치 정상 / 인증번호 정상 / 어휘 겹침)
    · 신호 11건 vs 화면 2건 — 허용 목록이 9건을 막았다는 것

  ★ 29.7% 라는 숫자는 README 에서 뺐습니다. 신호 지표를 화면 지표인 것처럼
    적은 것이 이번 오류의 전부이므로, 같은 자리에 다시 두지 않습니다.
    신호 기준 값이 필요하면 bench_eval_120.py 출력에 그대로 남아 있습니다.
