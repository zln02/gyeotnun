④ 카톡 공유 -> 곁눈  ★ 실기기 확인 필요
================================================================

  [서버측에서 확인 가능한 것 - 전부 정상]

  manifest share_target
    action=/share  method=POST  enctype=multipart/form-data
    files.name=image
    accept = image/png, image/jpeg, image/webp, .png, .jpg, .jpeg, .webp
    -> MIME 3개 + 확장자 4개 모두 있음 (MDN 권고 충족)
       ※ 8/2 에 확장자가 없어서 "곁눈은 열리는데 사진이 안 들어오는" 문제가
         있었고, 그때 고친 내용이 그대로 배포돼 있음을 재확인했다.

  서비스워커
    POST /share 를 가로채 이미지를 캐시에 저장 후 /?share=1 로 303 리다이렉트
    -> 코드 확인 완료

  수신 후 흐름
    /?share=1 로 진입했을 때 캐시에 이미지가 없으면
    "공유된 사진을 받지 못했습니다" + IN-003 안내가 뜬다 -> 확인 완료
    (실패해도 사용자가 막히지 않고 사진 올리기로 유도됨)

  PWA 설치 요건
    HTTPS / manifest / service worker / 아이콘 2종  -> 전부 충족

  [확인하지 못한 것 - 반드시 실기기로 해야 함]

  ★ 안드로이드 실기기에서 카톡 -> 공유 -> 곁눈 선택 -> 이미지 수신
    이 경로는 OS 의 공유 시트가 관여하므로 서버에서 검증이 불가능합니다.
    제가 확인한 것은 "설정이 올바르다"까지이고, "실제로 동작한다"는
    아직 아무도 확인하지 않았습니다.

  [내일 아침 실기기 점검 순서 - 10분]

    1. 안드로이드 폰 Chrome 으로 https://gyeotnun.duckdns.org 접속
    2. 메뉴(⋮) -> "앱 설치" 또는 "홈 화면에 추가"
       ※ 이미 설치돼 있다면 반드시 삭제 후 재설치할 것.
         manifest 가 바뀌었는데 옛 설정이 캐시돼 있으면 공유가 안 됩니다.
    3. 홈 화면 아이콘으로 한 번 실행 (정상적으로 열리는지)
    4. 카카오톡에서 아무 이미지 길게 누르기 -> 공유
    5. 공유 목록에 "곁눈" 이 뜨는가          <- 1차 관문
    6. 누르면 곁눈이 열리고 사진이 들어오는가 <- 2차 관문 (여기가 핵심)

    5는 되는데 6이 안 되면 = 파일이 첨부되지 않은 것.
      화면에 "공유된 사진을 받지 못했습니다 (오류 코드: IN-003)" 가 뜹니다.
      그 경우 사진 올리기 버튼으로 우회하면 테스트는 계속 가능합니다.

    ※ iOS 는 Web Share Target 미지원입니다. 아이폰 참가자는
      "사진 올리기" 버튼 경로로 안내해야 합니다.
