# 작업 보고 기록 (docs/reports/)

CLI 세션이 사용자에게 보고한 내용을 **복사해서 쓰기 좋은 평문(.txt)** 으로
남겨 두는 곳이다. 채팅 로그는 스크롤하면 찾기 어렵고, 기획서·발표자료에 옮길 때
마크다운 표가 깨지므로 고정폭 정렬한 텍스트로 따로 보관한다.

## 파일 이름 규칙

```
YYYY-MM-DD_주제.txt
```

예) `2026-08-02_OCR후보비교.txt`, `2026-08-03_임베딩검색채택.txt`

같은 날 같은 주제로 두 번 이상 남길 일이 생기면 뒤에 `_2` 를 붙인다.

## 파일 안에 반드시 들어갈 것

파일 첫머리에 아래 4줄을 둔다. 나중에 "이게 언제, 무슨 근거로 나온 숫자인지"를
파일만 보고 알 수 있어야 한다.

```
날짜   : 2026-08-02
주제   : OCR 후보 비교 (easyocr 채택 가부)
근거   : 표본 84건 실측 / 커밋 07c28eb
요청   : (사용자가 시킨 내용 한 줄 요약)
```

## 원칙

- **측정하지 않은 값은 쓰지 않는다.** 확인 못 한 항목은 "확인 못 함"으로 남긴다.
- 상세 분석·출처 링크는 `docs/evaluation/*.md` 에 두고, 여기에는 **결론과 표**를
  중심으로 옮긴다. 파일 끝에 원본 문서 경로를 적어 둔다.
- 수치가 나중에 갱신되면 **기존 파일을 고치지 말고 새 날짜로 새 파일**을 만든다.
  (언제 무엇이 바뀌었는지 추적할 수 있어야 하기 때문)
