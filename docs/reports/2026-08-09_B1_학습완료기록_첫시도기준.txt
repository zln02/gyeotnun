1. 원인 - 프론트 상태 하나가 덮어쓰기였다
--------------------------------------------------------------------
web/src/pages/Training.jsx

  const [answers, setAnswers] = useState({})
  function pickAnswer(choice) {
    setAnswers((prev) => ({ ...prev, [stepIndex]: choice }))   // ← 무조건 덮어쓴다
  }

  CompleteScreen:
    const correctCount = PRACTICE_STEPS.filter((s,i) => answers[i] === s.correct).length

answers 는 "지금 화면에 표시되는 선택"이다. 답변 후에도 O·X 버튼이 계속
활성 상태라(AnswerButton 에 disabled 가 없다) 다시 고를 수 있고, 이전 단계로
돌아가서 바꿀 수도 있다. 그런데 완료 화면이 **마지막 선택**을 세고 있었다.

★ 백엔드는 무관하다. GET /api/v1/training/today 는 카드만 준다.
  채점·기록·포인트는 전부 프론트 상태이고 서버에 저장되지 않는다.
  (그래서 이번 수정도 프론트 한 파일로 끝난다.)


2. 고친 방식 - 표시용과 기록용을 분리
--------------------------------------------------------------------
  answers       : 지금 화면에 표시되는 선택. 바꾸면 덮어쓴다. 피드백 표시용.
  firstAnswers  : 각 단계에서 **처음 고른** 답. 한 번 정해지면 덮어쓰지 않는다.
                  학습 완료 화면의 기록은 반드시 이 값으로 센다.

  function pickAnswer(choice) {
    setAnswers((prev) => ({ ...prev, [stepIndex]: choice }))
    setFirstAnswers((prev) => (prev[stepIndex] != null ? prev : { ...prev, [stepIndex]: choice }))
  }

왜 나누는가: 답을 바꿔 볼 수 있게 두는 것 자체는 학습에 필요하다 - 틀린 이유를
읽고 다시 고르는 게 이 연습의 핵심이다. 그 기능은 그대로 두고, **기록만**
사실대로 적는다.

바뀐 화면(학습 완료):
  전  "4/4   오늘 정답"        ← 고쳐 맞힌 것도 정답으로 셈
  후  "3/4   처음에 맞힘"
      "4문제 중 3개를 처음에 맞히셨어요. 나머지는 다시 보면서 바로잡으셨어요."
  카테고리별 카드(제목/기관명/숫자·조건/전체)도 첫 시도 기준으로 0건·1건 표기.

문구 원칙: 이 화면은 가족과 공유될 수 있다(파일 상단 주석의 팀 원칙).
  틀린 사실은 적되 부끄럽게 만들지 않는다 - "나머지는 다시 보면서
  바로잡으셨어요"를 붙여 고쳐 맞힌 것도 성과로 남긴다.

포인트: 지시대로 **그대로 지급**한다. 완주 기준 G 120, 변경 없음.

로그: 다시 고른 경우 practice_answer_<choice>_retry 로 구분해 남긴다.
      (종전에는 첫 선택과 재선택이 구분되지 않았다.)


3. 검증 - 실제 브라우저로 두 시나리오
--------------------------------------------------------------------
정적 빌드를 만들어 Playwright 로 직접 조작했다(개발 서버는 띄우지 않았다).

 시나리오 A (지적된 상황): 1단계 오답 → 정답으로 고침, 2~4단계 바로 정답
   OK  1단계 오답 피드백이 떴다(의도한 오답)
   OK  1단계에서 정답으로 고쳤다
   기록: 3/4 (처음에 맞힘)
   문구: 4문제 중 3개를 처음에 맞히셨어요. 나머지는 다시 보면서 바로잡으셨어요.
   카드: 0건 / 1건 / 1건 / 1건
   OK  포인트는 종전대로 G 120 이 지급된다
   → 전부 통과

 시나리오 B (대조군): 4단계 모두 처음에 정답
   기록: 4/4
   문구: 4문제 중 4개를 처음에 맞히셨어요.   ("나머지는…" 문구 없음)
   카드: 1건 / 1건 / 1건 / 1건
   → 통과 (무조건 깎는 로직이 아님을 확인)

 빌드: vite build 정상 종료.

4. 남는 것
--------------------------------------------------------------------
· 이 기록은 **회차 안에서만** 유효하다. 서버에 저장되지 않으므로 "지난주에
  무엇을 자주 틀렸는가"는 여전히 알 수 없다. 카테고리별 누적 이력 API가
  생기면 그때 연결한다(파일 주석의 기존 TODO와 같은 지점).
· 포인트도 실제 적립 API가 없는 고정값(G 120)이다. 이번 지시 범위 밖이라
  건드리지 않았다.
· 배포는 아직 하지 않았다. web/ 는 다른 세션이 함께 쓰고 있어 dist 를 새로
  만들면 그쪽 작업물까지 함께 나간다. 배포 시점은 지시를 받는다.
