1. 키를 공유하는가 → 그렇다 (같은 컨테이너, 같은 .env)
--------------------------------------------------------------------
docker-compose.yml 의 api 서비스가 `env_file: .env` 로 ANTHROPIC_API_KEY 를 읽고,
nginx 가 그 컨테이너(api:8000)로 프록시한다. 실험도 같은 컨테이너 안에서 돌렸다.
→ 운영 서비스와 실험이 **같은 키·같은 잔액**을 쓴다. 별도 키가 없다.
(키 값은 읽지도 출력하지도 않았다. 길이·설정 여부만 확인했다.)

    "이 글에 적힌 내용을 어느 기관에서 발표했는지 글 안에서 한번 찾아봐

4. 영향 범위 - 무엇이 죽고 무엇이 살아 있나
--------------------------------------------------------------------
  죽은 것(외부 API 의존)
   · 질문 생성(S3) : 고정 템플릿 1종으로 나간다. 글마다 다른 질문이 안 나온다.
   · 오판유형 태깅 : 규칙 기반으로 내려갔다(GN-002 3건).
                     화면 배지 문구가 LLM 분류보다 거칠어진다.

  살아 있는 것(전부 자체 서버 처리라 무관)
   · OCR(PaddleOCR 로컬) · 임베딩 검색(e5-small-ko-v2 로컬) · BM25
   · 사기사례 매칭 · 판정(verdict_hint) · 마스킹 · 근거 URL 표시
   · 위 라이브 점검에서도 근거는 정상으로 붙었다(bokjiro.go.kr 실제 문서 1건).

  사용자 화면
   · 오류 화면은 뜨지 않는다. 서비스는 계속 동작하고 질문만 고정 문구다.
   · 즉 '조용한 품질 저하'다. 지켜보지 않으면 모른다.
