0. ★ 먼저 — 1번은 착수하지 못했습니다
=====================================

  "사람이 준 초안에 <!-- CLI 검증 --> 주석이 있다" 고 하셨는데
  **초안이 메시지에 들어 있지 않습니다.**

  추측으로 README 를 새로 쓰지 않았습니다. 지시가 "그 자리를 실측값으로 채워라"
  이지 "새로 써라" 가 아니고, 어디에 무엇이 들어갈 자리인지도 초안에만 있습니다.

  대신 **채울 값은 오늘 전부 실측해 뒀습니다**(아래 1절). 초안을 주시면
  바로 채워 넣고, 초안 수치와 다른 곳만 따로 보고하겠습니다.

  같은 이유로 **5번(태그)도 보류**했습니다 — 지시가 "README 교체 후 태그" 입니다.
  태그 메시지에 넣을 수치도 아래에 준비돼 있습니다.

  2·3·4·6번은 초안과 무관하므로 전부 마쳤습니다.

        → "★★ 레거시 · 사용 안 함 · 대체: match_embedding_docs (임베딩 단독)"

        ★ 이게 이번에 새로 찾은 것입니다. 기존 주석이 이랬습니다:
            "collect_evidence() 는 **아직** 이 함수들을 쓰지 않는다 —
             어느 것을 쓸지는 벤치마크 결과를 보고 **사용자가 결정한다**"
          결정은 2026-08 에 이미 났고(임베딩 단독 채택·하이브리드 기각) 그
          결과가 같은 파일 아래쪽에 적혀 있는데, 위쪽 주석은 미결 상태로
          남아 있었습니다. **끝난 결정을 미결로 적어 두면 읽는 사람이 오해합니다.**
          근거_검증표 경로를 20일간 살려 둔 것과 같은 유형(대장 L1)이라
          주석에 그렇게 적었습니다.

        운영 경로 호출 0곳. 지금 부르는 곳은 experiments/exp_query_rewrite.py 뿐입니다.

        routers/ 어디에서도 부르지 않고 실험·테스트에서만 씁니다.
        연결 여부는 대장 M1 미결입니다.
