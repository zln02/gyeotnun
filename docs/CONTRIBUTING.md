# 기여 가이드 — 곁눈 (Gyeotnun)

## 역할은 두 층이다

전에는 표가 하나뿐이어서 기획서와 저장소가 서로 다른 말을 하는 것처럼 보였다.
**둘 다 사실이다. 층이 다를 뿐이다.**

- **표 1 팀 역할** — 기획서에 실린 대외 직함. 심사·기관 소개에서 쓰는 이름이다.
- **표 2 코드 폴더 담당** — 저장소에서 그 폴더를 누가 맡는지. 리뷰를 누구에게
  요청할지 정하는 실무용이다.

한 사람이 두 표에서 다른 이름을 갖는 것은 모순이 아니다. 기획서의 "사례 분석"은
산출물 기준이고, 저장소의 "태깅·코퍼스"는 파일 기준이다.

### 표 1 — 팀 역할 (기획서 기준, 대외 직함)

`docs/[2026년 제8회 K-디지털 트레이닝 해커톤] 예선심사과제_Second Look.pdf` p.10
"■ 팀원 역할" 을 그대로 옮긴 것이다. **여기 숫자·표현을 임의로 바꾸지 말 것** —
제출한 문서와 달라지면 그때부터 둘 중 하나는 거짓이 된다.

| 이름 | 역할 | 맡은 일 | 산출물 |
|---|---|---|---|
| **박진** | PM · 데이터 통합 | 통합 근거표 · 문제 정의 | 최종 기획서 |
| **김태희** | 공식 근거 검증 | 기관 · 연도 · 페이지 · URL | 근거표 |
| **장지석** | 사례 분석 | 중복 제거 사례표 | 대표 질문 |
| **박진영** | 백엔드 · 배포 | 공식 검색과 질문 생성 API | 배포 환경 |
| **김유리** | 프론트 · 시니어 UX | 공유 → 질문 → 판단 → 복습 | 화면 |
| **조희진** | UX 검증 · 데모 시나리오 · 성과 시각화 | 실제 화면 | 심사자료 시각화 |

### 표 2 — 코드 폴더 담당 (저장소 기준, 실무)

| 담당 | 영역 | 주요 파일 |
|---|---|---|
| **박진** | 인식 · 마스킹 | `api/services/ocr.py`, `api/services/masking.py` |
| **김유리** | 검색 · 공공데이터 대조 | `api/services/search.py` |
| **김태희** | 프롬프트 (판정 억제) | `api/services/prompt_chain.py` |
| **장지석** | 태깅 · RAG · 코퍼스 | `api/services/tagger.py`, `api/services/rag.py`, `corpus/` |
| **조희진** | 프론트 | `web/` 전체 |
| **박진영** | API · DB · 배포 | `api/main.py`, `api/routers/`, `api/models/`, `docker-compose.yml`, `deploy/` |

> 남의 폴더를 고쳐야 하면 먼저 담당자에게 말하세요.
> 단, `api/models/schemas.py`(계약서)는 **바꾸기 전에 반드시 팀 채널 공지**.

> **★ 커밋 저자 설정 (2026-08-15)**
> `git shortlog` 로 표 2 를 검증하려 했으나 **불가능했다.** 158 커밋 중 **152 건이
> `Ubuntu <ubuntu@ip-...>`** 라는 서버 공용 계정으로 남아 있다. 서버에서 작업할 때
> `git config user.name/user.email` 이 설정돼 있지 않아서다.
> **각자 자기 이름으로 커밋해야 표 2 가 나중에도 사실인지 확인할 수 있다.**
> ```bash
> git config user.name  "본인이름"
> git config user.email "본인메일"
> ```

## 협업 규칙

1. **매일 push.** 로컬에만 두고 자면 다음 날 합칠 수 없습니다.
2. **`.env` 절대 커밋 금지.** 커밋 전 `git status` 로 확인하는 습관.
3. **브랜치: `feat/{모듈}`** — `feat/ocr`, `feat/search`, `feat/prompt`, `feat/tagger`, `feat/web`, `feat/api`
4. `main` 직접 push 금지. PR → 담당자 1명 확인 → merge.
5. `models/schemas.py` (API 계약) 수정은 **팀 채널 공지 필수.**
6. 커밋 메시지: `feat(ocr): Vision OCR 연동` / `fix(web): 버튼 높이 56px 미달 수정`
7. 막히면 30분 안에 물어보기. 혼자 붙잡고 있는 시간이 가장 비쌉니다.
